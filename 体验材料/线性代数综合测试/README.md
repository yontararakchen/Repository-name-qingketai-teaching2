# 大学线性代数综合测试体验材料

这套材料用于完整体验轻课台的“教师建课 → 导入资料 → 发布测试 → 两名学生作答 → 教师查看结果/批改”流程。

## 材料清单

- `大学线性代数综合测试_试卷.pdf`：两道普通大学水平综合题的正式试卷。
- `大学线性代数综合测试_试卷.docx`：可编辑试卷源文件。
- `大学线性代数综合测试_课堂课件.pptx`：课堂讲解用课件。
- `线性代数综合测试_两道题.json`：题目结构化导入文件。
- `学生名单_两位.csv`：林晓、周宁两名学生名单。
- `学生1_林晓_正确答案.docx`：完整正确作答，用于验证高分批改。
- `学生2_周宁_故意错误答案.docx`：含参数分类、特征值计算等故意错误，用于验证错题识别和个性化反馈。

## 推荐演示顺序

1. 教师端新建课程“线性代数综合测试”，上传 PDF、PPTX 和 JSON 题库。
2. 导入 `学生名单_两位.csv`，确认林晓和周宁加入班级。
3. 发布包含两道题的课堂小测/作业。
4. 学生端分别以林晓、周宁进入；林晓提交正确答案，周宁提交故意错误答案。
5. 教师端打开活动结果，查看两人的选项/答案明细，分别批改并填写反馈。
6. 打开个性化作业，检查系统是否根据错题生成巩固练习和掌握度变化。

## 题目概要

1. 参数矩阵的秩分类、齐次方程基础解系，以及 `t=3` 时的非齐次方程。
2. 三阶实对称矩阵的特征值、单位特征向量、正交对角化和二次型表示。

# 线性代数基础班：完整体验顺序

1. 教师端打开“课程内容”，创建章节“第1章 矩阵基础”。
2. 在本文件夹选择学生名单 CSV，粘贴到“批量导入学生”。
3. 依次上传讲义 PDF、课堂课件 PPTX、例题 DOCX、公式 TXT；每次上传后确认资料列表出现“下载”。
4. 打开“课堂互动”，选择第1章，点击“开始课堂”。从课堂活动 JSON 或讲义中选择一道题，发布并在学生端回答。
5. 教师端打开“作业管理”新建作业，保存为草稿后发布；学生端保存草稿、添加文字答案并提交，教师端进入“学生提交”评分并导出 CSV。
6. 教师端打开个性化作业，选择一名学生和第1章，生成草稿、审核发布；学生端完成后提交，教师端评分，随后在“知识点掌握”查看掌握度证据回写。

建议先使用 `线性代数基础班_学生名单.csv`，再使用其他文件。所有材料均为可直接体验的示例，内容围绕同一章“矩阵基础”。
